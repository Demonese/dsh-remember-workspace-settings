# 用户的原始要求

> 注意：该文档由用户维护。

> 该文档记录用户的原始要求，作为整个插件功能设计、代码实现的依据。

DeepSeek Harness（以下简称 DSH）可以添加多个工作区，新建对话时可以选择预设（标准模式、PTC 模式、……）、模型（供应商 + 模型 + 思考强度）。

实际体验下来，原生 DSH 存在以下缺口：

- 只有全局的默认预设设置，无法针对工作区单独设置
- 上次新建对话时选择的模型会记下来，但工作区之间没有隔离

为了解决上述问题，需要开发一个插件，填补原生 DSH 的缺口，改善使用体验。简单来讲，就是在多个工作区频繁新建对话时不需要反复选预设和模型。

需要实现的功能：

- 工作区设置包含预设、模型（供应商 + 模型 + 思考强度）
- 在工作区新建对话，选择预设、模型会将选项保存在工作区设置中
- 下次在同一个工作区新建对话时，读取工作区设置并应用

为了保持插件简洁，不做：

- 设置界面等前端UI
- 为了完美实现需求将插件代码复杂化，甚至修改 DSH 源码

DSH 的架构并不完美，一些边界情况如果难以通过官方 API 解决，可以放它一马。
